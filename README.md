# work-calendar

여러 회사가 한 달력에서 작업을 요청하고 "완료"를 누르는 협업 캘린더입니다. 로그인 없이 초대 링크(`#r=키`)만으로 씁니다.

- 기능: 작업 요청과 일정(시간 포함), 본문(최대 5,000자), 첨부(파일 700KB·링크·유튜브 재생·HTML 열기), 회사별 색·필터, 실시간 반영
- 호스팅: GitHub Pages · 데이터: Firebase Firestore (무료 플랜) · 디자인: Apple iOS/iPadOS 27 UI kit 기준
- 사용: 페이지를 열어 "새 캘린더 만들기" → 초대 링크를 팀에 공유 → 각자 이름·회사 입력
- 개발: `npm test` (단위), `npm run test:rules` (규칙, 실제 프로젝트), 로컬 미리보기 `python3 -m http.server 8765`
- 설계서: `docs/superpowers/specs/2026-09-14-work-calendar-design.md`

## 알아 둘 한계 (v1)

- 링크가 곧 열쇠입니다. 링크를 아는 사람은 누구나 보고, 고치고, 지울 수 있습니다. 함께 일할 사람에게만 보내세요.
- 로그인이 없어 서버는 "누가" 쓰는지 모릅니다. 공개 저장소의 Firebase 설정으로 누구든 새 캘린더·항목을 만들 수 있으므로, 이론상 무료 한도(하루 쓰기 2만·저장 1GB)를 남이 소진시킬 수 있습니다. 갑자기 "저장하지 못했습니다"가 계속되면 이 경우일 수 있고, 그때는 Firebase App Check(reCAPTCHA) 적용이 다음 단계입니다.
- 60일 넘게 지난 달의 항목은 열 때 한 번만 불러오며, 그 사이 다른 사람이 지운 항목은 새로고침 전까지 남아 보일 수 있습니다. 60일 넘게 이어지는 항목은 실시간 갱신에서 빠질 수 있습니다.
- 첨부 내용은 Firestore 문서라서 하루 무료 읽기(5만 건)와 전송량을 함께 씁니다. 동영상 같은 큰 파일은 링크로 붙이세요.
- HTML 첨부는 앱 안 샌드박스(스크립트만 허용, 앱과 다른 출처)에서 열립니다. 첨부 안의 링크·폼은 동작하지 않을 수 있습니다.
